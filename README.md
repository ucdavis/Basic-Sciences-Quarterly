# Basic Sciences Quarterly

Newsletter of the Office of the Vice Dean for Basic Sciences, UC Davis School of Medicine.

Each issue lives in its own folder under `public/` (for example `public/2026-q3/`) and keeps a stable URL. Only `public/` is published, through GitHub Pages and the workflow in `.github/workflows/deploy-pages.yml`.

See `HOWTO-GitHub-Setup.md` for the per-quarter checklist.
